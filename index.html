Hermes VPS Google Drive

This personal integration lets its owner use their own Hermes assistant to manage Google Drive files from a private server.

It supports listing files, creating folders, uploading and downloading files, renaming and moving files, and moving files to Drive trash. Google Drive storage is used on demand; the application does not automatically synchronize the whole Drive.

这个个人自用工具让机主通过自己的 Hermes 助手管理 Google Drive，支持文件上传、下载、文件夹创建、重命名、移动及移入垃圾箱。只有账号本人主动授予 Google 权限后，助手才能访问云盘。

This is an independently operated personal integration. It is not affiliated with Google or the Hermes upstream project. This website only provides application information and policies; it contains no sign-in form, Drive files, access tokens, or server administration interface.
