Hermes VPS Google Drive

Privacy policy / 隐私说明

This application is operated by its account owner for personal use. It requests only the Google Drive OAuth permission. It does not request access to Gmail, Calendar, or Contacts.

Access and use

With the owner's authorization, the application accesses Drive account identity, storage quota, file and folder metadata, and file content needed to carry out the owner's instructions. The granted Drive scope allows viewing, creating, editing, and deleting Drive files. The supplied file-management helper uses recoverable trash for removal.

Storage and retention

OAuth client configuration and refresh credentials are stored on the owner's private server in files restricted to the Hermes operating-system user and server administrator. They are not stored on this public website or in this public repository. Downloaded files and generated files can be stored on the private server; uploaded files remain in Google Drive. Hermes conversations and tool results may retain metadata or content from requested operations according to the owner's existing local retention settings. The owner can remove local copies and conversations and manage Drive files directly.

Sharing and AI processing

File operations use Google's Drive API. When the owner asks Hermes to analyze or work with file content, necessary content or tool results may be sent to the AI model provider configured by the owner for that task. The operator uses Google user data only to provide the requested personal-assistant features and does not sell it, use it for advertising, or use it to train generalized AI models. This website does not host, collect, or publicly share Drive data. Public web hosting may process ordinary web request logs under the hosting provider's policy.

Human access to Google user data is limited to the owner, explicitly authorized troubleshooting, security investigation, or legal obligations. The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Control and revocation

The owner can revoke this application's access at Google Account connections at any time. Revocation prevents future authorized API access but does not automatically delete files already downloaded, uploaded, or retained in conversations. The owner controls deletion of those copies. Google may expire or revoke credentials independently.
